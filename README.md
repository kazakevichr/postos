# Postos

Система управления партнёрской сетью и расчёта мотивации сотрудников. Реализована на основе обсуждения экономики проектов Oracle, SUPERFIT24, Velar24, VPN и Музлото.

Стек: Next.js 14 (App Router, TypeScript) + PostgreSQL/SQLite + Prisma + NextAuth + TailwindCSS.
Для локального запуска используется SQLite (файл `dev.db`) — не нужно поднимать отдельный сервер БД.

## Что реализовано

- Авторизация (email + пароль), роли Владелец / Менеджер.
- Дашборд: сводка по проектам (партнёры, активные, доход за месяц, конверсия) и по сотрудникам (партнёров, активных, KPI, к выплате).
- Канбан-доска партнёров по проекту с настраиваемыми стадиями воронки и переходами между ними.
- Карточка партнёра: контакты, ответственный, ключевые даты, лог транзакций (доход → автоматический расчёт прибыли владельца), история стадий, комментарии, отметка "упущен".
- Автоматический расчёт KPI (при достижении партнёром целевой стадии) и ежемесячного бонуса (% от прибыли партнёра, с порогом, капом и ограничением по периоду) — всё настраивается в интерфейсе, не в коде.
- Вкладка "Зарплата": оклад + KPI + бонус по каждому сотруднику, с разбивкой по проектам, за любой месяц.
- Вкладка "Упущенные партнёры" с причиной отказа и напоминанием, когда попробовать снова.
- Задачи: список на сегодня/просрочено, чекбоксы, создание вручную.
- Настройки (только владелец): параметры проектов (валюта, формула прибыли, KPI, бонус, типы партнёров вроде "Блогер"/"Сертификат" для Музлото) и список сотрудников.

## Запуск локально

Требования: Node.js 20+, npm.

```bash
cd postos
npm install              # поставит зависимости и сгенерирует Prisma Client
npx prisma migrate dev --name init   # создаст dev.db и таблицы
npm run seed              # заполнит демо-данными (проекты, партнёры, сотрудники)
npm run dev                # http://localhost:3000
```

При `npm install` Prisma автоматически скачивает движок базы данных из интернета — это нормально, для этого нужен обычный доступ в сеть (шаг `postinstall: prisma generate`).

Обязательно смените `NEXTAUTH_SECRET` в `.env` перед реальным использованием (сейчас там тестовое значение).

## Деплой

Постос живёт в Coolify на своём сервере, за доменом postos.dobro-inc.com. Раскатка
автоматическая: push в `main` → GitHub дёргает вебхук Coolify → сборка и перезапуск.
Нажимать Redeploy руками не нужно; кнопка остаётся на случай, когда надо пересобрать
без новых коммитов.

Схема базы обновляется сама при старте — команда запуска приложения выполняет
`prisma db push` перед `next start`, поэтому новые поля приезжают вместе с кодом.
Отдельного шага миграции нет.

Переменные окружения задаются в Coolify (Environment Variables), а не в репозитории:
их список с пояснениями — в `.env.example`. После правки переменной нужен перезапуск,
сам по себе push её не подхватит.

## Что не входит в эту версию (см. ТЗ, раздел 12)

- Нативное мобильное приложение (есть адаптивная веб-версия).
- Уведомления в Telegram/WhatsApp.
- Автоконвертация валют по курсу.
- Drag-and-drop на канбан-доске — сейчас перемещение партнёра между стадиями делается кнопками "← Назад" / "Далее →" на карточке (быстрее было сделать надёжно, чем тащить библиотеку drag-and-drop; при желании легко заменить на dnd-kit).
